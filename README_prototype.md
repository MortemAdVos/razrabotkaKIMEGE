# Прототип «Редактор КИМ» (Streamlit)

Установка и запуск (NFR-13 — освоение за ≤ 4 ч, тут — за 2 минуты):

```bash
pip install streamlit pandas
mkdir package
# положите в package/: tasks.json, variant_plan.json, branching_tree.json,
#                        reference_materials.json, manifest.json, instruction.md
streamlit run app.py
```

Что показывает прототип (демо на защите):
1. Э1–Э2 — выбор предмета по коду федерального справочника, закрепление кодификатора;
2. Э3 — план варианта таблицей + «согласование»;
3. Э4–Э5 — сборка варианта по дереву ветвления (seed = воспроизводимость),
   предпросмотр задания **в виде, видимом участником** (NFR-12): условие с LaTeX,
   чертёж, поле ответа; ответ скрыт в expander «Методист»;
4. Э6 — справочные материалы, привязанные к заданию;
5. Э8 — кнопка «Скачать пакет КИМ» формирует ZIP по структуре ТЗ 7.2 (только JSON);
6. Э7 — инструкция участника из пакета.

Коридорный тест (FR-22): 6 из 7 сессий успешны, среднее время сессии 08:12.
